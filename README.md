# Disneyland Review Analysis System
A modular Python application designed to process, visualize, and export global theme park review data.

## Overview
This system allows users to interact with a large dataset of Disneyland reviews. It features a Terminal User Interface (TUI) for data exploration, statistical analysis, and dynamic data visualization using Matplotlib.

## Key Features
- **Data Exploration:** Filter and view reviews by park name, reviewer location, and date.
- **Statistical Analytics:** Calculate average ratings and review counts across different global branches.
- **Data Visualization:** Generate Bar Charts and Pie Charts to visualize park popularity and score trends.
- **Multi-format Export:** Export processed analytics into **CSV, JSON, and TXT** formats for external reporting.

## Tech Stack
- **Language:** Python 3.x
- **Libraries:** Matplotlib (Visualization), CSV & JSON (Data Handling)
- **Architecture:** Modular Design (Separated Logic, UI, and Exporting modules)

## How to Use
1. Clone the repository.
2. Ensure you have `matplotlib` installed (`pip install matplotlib`).
3. Run `python main.py` to launch the interactive menu.
